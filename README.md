# TI-59 Zombie

**Emulatore della calcolatrice Texas Instruments TI-59 su ESP32-S3 — TI-59 calculator emulator on ESP32-S3**

Riproduzione fedele della calcolatrice programmabile TI-59 (1977) basata sull'emulazione del microprocessore TMC0501, con interfaccia web integrata che funge anche da IDE. Firmware Arduino per ESP32-S3 (DevKitC-1 N8R8). — Faithful reproduction of the TI-59 programmable calculator (1977), based on emulation of the TMC0501 microprocessor, with an embedded web interface that also acts as an IDE. Arduino firmware for the ESP32-S3 (DevKitC-1 N8R8).

Tutti i commenti del codice e i testi sono bilingui (italiano — inglese). — All code comments and UI texts are bilingual (Italian — English).

## Caratteristiche — Features

- **Emulazione completa del core TMC0501**: DSCOM, BROM, RAM, stack subroutine a 8 livelli, registri dati BCD, flag utente, indicatori INV/2nd. — **Full TMC0501 core emulation**: DSCOM, BROM, RAM, 8-level subroutine stack, BCD data registers, user flags, INV/2nd indicators.
- **Pacing a tempo reale**: velocità identica al TI-59 originale (~7.100 istruzioni/s) con modalità "Old/New" regolabile dal web. — **Real-time pacing**: same speed as the original TI-59 (~7,100 instr/s) with a web-tunable "Old/New" mode.
- **14 moduli libreria "Solid State Software"** con numerazione ufficiale (vedi sotto). — **14 "Solid State Software" library modules** with official numbering (see below).
- **Schede magnetiche emulate** come file JSON in SPIFFS (lato A/B da 480 passi, registri), con microswitch card-sense. — **Magnetic cards emulated** as JSON files in SPIFFS (480-step sides A/B, registers), with a card-sense microswitch.
- **Lettore NFC opzionale** (MFRC522 + tag NTAG213) che riproduce il flusso READ/WRITE del lettore originale, con espulsione motore. — **Optional NFC reader** (MFRC522 + NTAG213 tags) reproducing the original reader's READ/WRITE flow, with motor ejection.
- **Stampante termica** BLE (backend NimBLE) per l'emulazione della stampante PC-100A. — **BLE thermal printer** (NimBLE backend) for the PC-100A printer emulation.
- **Display a 12 digit** pilotato da HT16K33 (16x8, I2C). — **12-digit display** driven by an HT16K33 (16x8, I2C).
- **Web IDE integrato**: calcolatrice virtuale, gestione programmi/schede/moduli, editor overlay con anteprima, pannello posizioni SVG. — **Embedded web IDE**: virtual calculator, program/card/module management, overlay editor with preview, SVG position panel.
- **i18n italiano/inglese** selezionabile dalle pagine web. — **Italian/English i18n** selectable from the web pages.

1. Apri `ti59_zombie.ino` in Arduino IDE (1.8.x o 2.x). — Open `ti59_zombie.ino` in Arduino IDE (1.8.x or 2.x).
2. Installa il core **esp32** di Espressif (Board Manager) e seleziona la scheda **ESP32S3 Dev Module** (8MB flash / 8MB OPI PSRAM, via USB-Serial-JTAG). — Install the Espressif **esp32** core (Boards Manager) and select **ESP32S3 Dev Module** (8MB flash / 8MB OPI PSRAM, USB-Serial-JTAG).
3. Librerie richieste — Required libraries: **MFRC522** (solo RFID — RFID only) e **NimBLE-Arduino** (solo stampante BLE — BLE printer only). 4. Flash del firmware. — Flash the firmware.
5. Carica la cartella `data/` sul file system SPIFFS (strumento "ESP32 Sketch Data Upload" o `esptool` sulla partizione SPIFFS). — Upload the `data/` folder to the SPIFFS filesystem ("ESP32 Sketch Data Upload" tool or `esptool` on the SPIFFS partition).

Al primo avvio la scheda apre un **captive portal WiFi** (pagina `/setup`) per inserire le credenziali di rete, salvate nel file `/wifi.json` su SPIFFS (caricabile con la cartella `data/`). — On first boot the board opens a **WiFi captive portal** (page `/setup`) to enter network credentials, stored in the `/wifi.json` file on SPIFFS (flashable with the `data/` folder).

## Sicurezza — Security

- Le credenziali WiFi vivono nel file **`/wifi.json`** su SPIFFS (niente hardcoded, niente NVS), scaricabile/modificabile/ricaricabile dal portale `/setup` (`GET`/`POST /api/wifi/file`). Nota: il file contiene le password in chiaro — appartiene al proprietario del device. — WiFi credentials live in the **`/wifi.json`** file on SPIFFS (no hardcoding, no NVS), downloadable/editable/reloadable from the `/setup` portal (`GET`/`POST /api/wifi/file`). Note: the file contains plaintext passwords — it belongs to the device owner.
- Il pannello `/wolf` (god mode) si attiva solo se su SPIFFS esiste `/god_mode.txt`. — The `/wolf` (god mode) panel only activates if `/god_mode.txt` exists on SPIFFS.
