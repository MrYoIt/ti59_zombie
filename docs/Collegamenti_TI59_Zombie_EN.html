LiPo power

  • LiPo3.7V (2 pins B+/B−)→ charging module
  • SWSPST switchon the positive rail
  • 5VDevKitC-1 5V pinonboard regulator

The charging module does NOT pass current while charging (internal diode): without a battery the device won't turn on even with the charger connected.

RECOMMENDED ASSEMBLY ORDER:
1. Keyboard (Section 2) and verify scan from the web (/api/keypress)
2. Display (Section 3) — expect "HELLO" at boot
3. LiPo power (Section 1), test pin voltages before connecting the rest
4. microSD, then the NFC reader (Section 4–5) and verify MFRC522 detected at boot
5. Microswitch + eject motor, test READ/WRITE with an NTAG213 tag

FINAL CHECK: measure that there are no shorts between 3V3 and GND before powering on.
GPIO45 NOTE: strapping pin — fine as output; avoid grounding it at boot.
CRITICAL: no access to GPIO22–34/35–37 — writing to the flash/PSRAM bus blocks the flash and causes a WDT reset loop (rst:0x8 TG1WDT_SYS_RST).
CRITICAL: the console is on USB-Serial-JTAG (GPIO19/20): for the monitor you need a USB 2.0 port (D−/D+ present), baud 115200.
